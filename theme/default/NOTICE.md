# Theme provenance

The site theme is maintained here as a single stylesheet, with its own tree navigation, TOC, index layout and Noto Serif typography. There is no upstream/adaptation layer.

Earlier styling was derived from Kodama Project CSS embedded in:
https://github.com/kodama-community/kodama-community.github.io/blob/b7c2c87a51631785e60c08818824b984fda5e6bb/publish/index.html

Kodama Project attribution and the GPL-3.0 license are retained for derived portions; see LICENSE. Renaming and restructuring do not remove that provenance.

Noto Serif and Noto Serif SC load via Google Fonts. Offline fallback uses local serif fonts. Code keeps a monospace stack; Typst controls mathematical fonts.
